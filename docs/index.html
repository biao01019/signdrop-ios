「直接安装」需要 IPA 已被签名。这个包是未签名的原始包，iOS 会拒绝安装。请先用 Sideloadly / AltStore 用自己的 Apple ID 签一次，或改用下方步骤。
用 Apple ID 自签安装
1

电脑装 Sideloadly

Windows / macOS 均可，官网直接下载安装。

2

手机连电脑，拖入 IPA

填自己的 Apple ID，点 Start，等待签名完成。

3

信任开发者证书

设置 → 通用 → VPN与设备管理 → 选中你的 Apple ID → 信任。

4

打开 Signdrop，导入 IPA 再签一次

首页 + 添加 IPA → 用 App 内 Apple ID 直签，7 天有效，到期重签即可。
